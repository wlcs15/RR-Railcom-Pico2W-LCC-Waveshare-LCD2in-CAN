Required on Windows 11 and Ubuntu x86. Nothing in these scripts installs a tool.

Host checks:
  git, Python 3, CMake, LLVM Clang, Ninja, lizard, llvm-cov, llvm-profdata
  Unity is vendored at third_party/Unity

Firmware:
  Pico SDK 2.2.0 at ~/.pico-sdk/sdk/2.2.0 (or PICO_SDK_PATH)
  ARM GNU 14.2 at ~/.pico-sdk/toolchain/14_2_Rel1 (or PICO_TOOLCHAIN_PATH)
  picotool 2.2.0-a4
  Ninja may live at ~/.pico-sdk/ninja/v1.12.1

On-target emulators (required for CI smoke; not Espressif QEMU or simavr):
  qemu-system-arm   Cortex-M33 / RP2350 semihosting smoke (QEMU system ARM)
  renode            RP2040 / Pico W Renode smoke
  qemu-system-aarch64  optional companion softmmu (report only; not required for Pico M0/M33)
  Prefer /workspace/tools/bin on PATH when present (see workspace EMULATORS.txt /
  source /workspace/env/emulators.sh). System package installs are also accepted.

Emulator test wrappers (no hardware flash):
  bash scripts/run_emulator_tests.sh          # qemu-system-arm cortex-m33 smoke of lcc_node.elf
  bash scripts/run_emulator_tests.sh --renode # Renode RP2040 smoke (pico_w ELF)
  Matching scripts/run_emulator_tests.py and .ps1

The host tests use Clang. Do not point them at MinGW gcc.
The LCC image is flashed over the Pico micro-USB port. The three-pin SWD header is not required.
